## 视觉与内容

- 产品图标采用彩色笔记本：竹青封面 `#3B8C76`、深青书脊 `#185F50`、暖白纸页 `#FFF9EA`、金杏书签 `#E6AD54` 与青色笔迹 `#286B5D`。侧栏激活态使用 `#28765F`；产品图标与 README 共用同一几何。
- 操作图标采用 Open Design K3 的方向 A「墨线 / Inkline」，使用 24×24 网格、2px 圆端描边和 `currentColor`，常用控件显示为 16px。产品图标保留彩色填充，操作图标继承 DSH 主题颜色。
- 图标为可维护的纯 SVG，没有脚本、`foreignObject`、外部字体或外部图片。摘录图标先从剪刀改为选区与文字线，0.2.5 再改为「引用竖线 + 文字 + 加号」，避免与剪切、截图混淆；保存动作图标与已保存状态文案分别保留。
- 首页顺序：图标与定位 → 真实工作台与版本提示 → 为什么用 → 安装／升级／卸载 → 能力与对话侧栏 → 可选 AI → 快捷键 → 常见问题 → 兼容性与详细文档。
- 发布首页以 npm 安装为主，源码构建折叠放在后面；GitHub 版本、npm 和问题反馈入口集中列出，不展示未经验证的 CI 徽章或用户规模。
- 存储结构、详细额度、导出还原限制和 Native 快捷键协议留在使用指南／验证记录。

中英文 README 经 GitHub Markdown API 渲染并检查桌面／手机宽度、图片加载与链接的初次记录属于 **0.2.0**。0.2.2 曾重新渲染，在 1280px 桌面和 390px 手机宽度检查了产品图标、两张截图与横向溢出。0.2.5 换图及改文案后需单独复核；旧版审计不代替本次检查。预览文件位于被忽略的 `artifacts/readme-preview`，不随插件发布。

## 发布文案

GitHub 仓库使用 `Totoro-qaq/dsh-jot`，包名使用 `dsh-jot`。首页首句说明「DSH 中直接写笔记、待办和轻文档，可选 agent 协作」，功能按写、找、资料、保存与导出五组介绍。附件优先复用官方预览，Office 转 PDF、表格及其他查看器的可用性取决于宿主；内部预览、默认应用打开副本和下载分别说明，不暗示原位 Office 编辑或外部应用自动回写。兼容声明区分源码支持的 rc.2／alpha.1 与实际宿主、操作系统验收；源码检查、图片拍摄及发布成功分开记录。

## 2026-10-04 修订

- **产品图标：** 原图标在 16px 侧栏中容易被看成表格／文档类文件图标（绿色矩形、白色纸页加两条横线）。新版让金杏色书签伸出封面顶部、打破矩形轮廓，并把纸页上的两条线改为一个勾选标记和一条线，呼应「笔记 + 待办」。配色与 24×24 网格不变，README 图标与 `assets/icons/product.svg` 共用同一文件内容，并由测试检查一致。
- **操作图标：** 摘录从「四角取景框」改为「引用竖线 + 文字 + 加号」，避免被理解为截图或文字识别；查找上下一个改用上下箭头；补充重命名（铅笔）、恢复、排序、隐藏列表和 AI 图标。`assets/icons` 由 `pnpm icons` 从 `src/client/icons.tsx` 生成，不再手工维护。
- **README 结构：** 首页改为「为什么用 → 能做什么 → 安装／升级／卸载 → 三步开始 → 和 AI 一起用 → 快捷键 → 数据 → 兼容性表 → 常见问题」。测试数量、K3 来源、插件样式隔离等维护信息移到更新记录、验证记录和本文件；版本号改用 npm 徽章，不再在多个文档里手写。新增英文使用指南 `docs/GUIDE.en.md`。
- **0.2.5 截图替换：** 已完成中英文两组真实宿主图片。侧栏展示原样迁入的真实公开对话；新工具栏、图标与左对齐布局来自当前构建。
- **交互边界：** 三条命令默认无绑定，测试用按键不作为默认键。Web 和 Native 的命令、深色与表格结果按实际候选分别记录于验证文档；Native Escape 取消拖动尚未单独实测。最终左对齐 Web 截图已完成，Desktop 新布局已在普通窗口与全屏中单独复核。
